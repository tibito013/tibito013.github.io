As imagens atuais foram geradas para este projeto conceitual e não representam clientes reais.

Para substituí-las no futuro, mantenha estes nomes:
- hero-atendimento.webp — atendimento/corte, proporção 4:5, recomendado 1200 × 1500 px.
- ambiente-barbearia.webp — ambiente interno, proporção 4:5, recomendado 1200 × 1500 px.
- galeria-ferramentas.webp — ferramentas e materiais, proporção 3:2, recomendado 1500 × 1000 px.
- galeria-estacao.webp — cadeira ou estação de trabalho, proporção 3:2, recomendado 1500 × 1000 px.

Pasta: projects/barbearia/assets/images/

O CSS usa object-fit: cover. Portanto, imagens com essas proporções podem ser trocadas sem refazer o layout.
